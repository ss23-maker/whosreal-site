# whosreal.site

The website for the Who's Real? game. Served by GitHub Pages at https://whosreal.site.

- `index.html` the home page, with a playable sample round
- `privacy.html` the game's privacy policy
- `app-ads.txt` tells advertisers the game's AdMob ad space is genuine
- `fonts/` the site fonts, hosted here so pages make no outside requests
- `.well-known/security.txt` who to contact about a security issue
